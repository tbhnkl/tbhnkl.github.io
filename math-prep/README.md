# הכנה למבחן מתמטיקה

אפליקציית ווב אישית, מותאמת למובייל, לתרגול לקראת מבחן מתמטיקה. סטטית
לגמרי, ללא שרת: קובץ ה-PDF נטען ומעובד רק בדפדפן שלך (`File`/IndexedDB
מקומיים), ולעולם לא נשלח לשום מקום — חשוב במיוחד כשמדובר בחומר מוגן
בזכויות יוצרים כמו מבחן אישי.

חי בנתיב `/math-prep/` באתר, בנפרד מהאפליקציות האחרות שבשורש הריפו.

## איך זה עובד

1. **מסמכים** – מעלים קובץ PDF. הוא נשמר ב-IndexedDB של הדפדפן (לא
   מועלה לאף שרת), כך שאפשר לחזור אליו גם בפעם הבאה בלי להעלות שוב.
2. **כרטיסיות** – כל עמוד (או שאלה, ראו "פירוק אוטומטי" למטה) מוצג ככרטיסייה
   נפרדת: ניווט קודם/הבא, זום, וסימון "יודע" / "חלקית" / "לא יודע".
   אפשר גם לפרק כל כרטיסייה ידנית ל"שלבי פתרון" ולסמן מה כבר הבנתם,
   ולהוסיף הערות חופשיות.
3. **נושאים** – מתייגים כל כרטיסייה בנושא אחד או יותר (קמירות, תכנון
   לינארי וכו'). טאב "נושאים" מציג לכל נושא כמה שאלות מתויגות וכמה
   אחוז מהן "ידועות" — כדי לעקוב אחרי התקדמות **לפי נושא**, לא רק לפי
   שאלה בודדת, ולאורך כמה מבחנים/PDF-ים לאורך זמן (הנושאים משותפים לכל
   המסמכים).

## פירוקים מוכנים מראש

עבור קורס "Mathematical Tools in CS" הספציפי (`EX1_sol.pdf` עד
`EX11_sol.pdf`), האפליקציה **כבר מכילה** פירוק מלא: 44 שאלות מכל 11
התרגילים, כל אחת עם נושא (או כמה נושאים) וצ'קליסט שלבי-פתרון שמדגיש את
הטריק המרכזי בכל שלב — לא רק את הפתרון המלא. פשוט מעלים את ה-PDF, והכל
מופיע אוטומטית: אין צורך ב"פרק אוטומטית" או "ייבוא JSON" ידניים. פרטים
טכניים ב-`manifests/README.md`. כמובן שהתיוג לנושאים ניתן לעריכה מלאה —
אפשר להסיר נושא לא מתאים או להוסיף נושא נוסף לכל שאלה, בדיוק כמו בכל
כרטיסייה אחרת.

עשרת הנושאים המוגדרים כברירת מחדל תואמים את הקורס עצמו: גבולות ורציפות,
נגזרות, קמירות, אופטימיזציה קמורה וגרדיאנט, KKT ולגראנז', תכנון לינארי
ודואליות, אלגברה לינארית ומטריצות, תורת גרפים ספקטרלית, הסתברות ותוחלת,
ושיטות הסתברותיות וריכוז — אבל גם אלה ניתנים לעריכה/הוספה חופשית.

## שלב 2: פירוק לשאלות (למסמכים אחרים)

יש שתי דרכים לפרק PDF לכרטיסיות-שאלה נפרדות (במקום עמוד-עמוד):

### א. פירוק אוטומטי (בכפתור, בלי לצאת מהאפליקציה)

הכפתור "פרק אוטומטית 🪄" במסך הכרטיסיות מנתח בעצמו, בדפדפן, את שכבת
הטקסט של ה-PDF: הוא מחפש שורות שנראות כמו כותרת שאלה — "Problem 3."
או "שאלה 3" (עם או בלי כותרת בסוגריים) — ובונה כרטיסייה לכל שאלה, מ
תחילת הכותרת שלה ועד רגע לפני הכותרת הבאה, גם אם זה חוצה עמוד. זה עובד
טוב על מסמכים שנוצרו מ-LaTeX/וורד עם כותרות שאלה עקביות (למשל "תרגילי
בית" עם "Problem N." ואחריו "Solution N." על אותה שאלה). הוא גם מציע
נושאים לפי מילות מפתח בכותרת (לדוגמה "convex" → קמירות) — כדאי תמיד
לעבור ולתקן ידנית, זו רק הצעה.

זה **לא** יעבוד על PDF סרוק כתמונה (בלי שכבת טקסט) — לשם כך צריך את
האפשרות הבאה.

### ב. ייבוא ידני/בעזרת Claude (JSON)

כדי לשלוט בפירוק במדויק (או לטפל בקובץ סרוק), שתפו את ה-PDF עם Claude
ובקשו לייצר קובץ `questions.json` לפי הסכימה הבאה, ואז ייבאו אותו
במסך "כרטיסיות" → "ייבוא JSON":

```json
{
  "version": 2,
  "questions": [
    {
      "id": "q1",
      "label": "שאלה 1",
      "regions": [
        { "page": 1, "crop": { "x": 0, "y": 0.12, "w": 1, "h": 0.4 } },
        { "page": 2, "crop": { "x": 0, "y": 0, "w": 1, "h": 0.2 } }
      ],
      "topics": ["קמירות", "תכנון לינארי"],
      "steps": ["הצבה בנוסחה", "בדיקת תנאי קמירות", "מסקנה"]
    }
  ]
}
```

- `regions` — רשימת קטעי עמוד שמרכיבים את השאלה, לפי הסדר. כל קטע הוא
  `{ page, crop }` כאשר `page` הוא מספר העמוד (1-מבוסס) ו-`crop`
  אופציונלי — מלבן יחסי לעמוד (ערכים 0–1, `y`=0 זה **ראש** העמוד). בלי
  `crop`, הקטע מציג את העמוד המלא. שאלה שלא חוצה עמוד יכולה להסתפק
  ב-`regions` עם איבר אחד.
  לתאימות לאחור נתמך גם הפורמט הישן: `"page": 1, "crop": {...}` יחיד
  במקום `regions`.
- `topics` — שמות נושאים (נוצרים אוטומטית אם לא קיימים).
- `steps` — רשימת שלבי פתרון מוצעים; מתווספים לרשימה הידנית הקיימת.

שני מסלולי הפירוק לא מוחקים התקדמות קיימת (סימון ידוע/לא ידוע, הערות,
שלבים) — הם רק מוסיפים/מעדכנים נושאים, תוויות ושלבים על אותה כרטיסייה
(`id`).

## טכנית

- `assets/app.js` — כל הלוגיקה (IndexedDB, רינדור PDF, מצב UI), ES module יחיד, ללא תלויות build.
- `assets/vendor/pdfjs/` — [pdf.js](https://mozilla.github.io/pdf.js/) (MIT), מגובה מקומית מ-npm כדי שהאתר לא יהיה תלוי ב-CDN חיצוני.
- שמירה: IndexedDB (`documents`, `cards`, `topics`) + `localStorage` למסמך האחרון שנפתח. הכל מקומי למכשיר.

לבדיקה מקומית:

```
python3 -m http.server 8000
# פתחו http://localhost:8000/math-prep/
```
