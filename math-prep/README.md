# הכנה למבחן מתמטיקה

אפליקציית ווב אישית, מותאמת למובייל, לתרגול לקראת מבחן מתמטיקה. סטטית
לגמרי, ללא שרת: קובץ ה-PDF נטען ומעובד רק בדפדפן שלך (`File`/IndexedDB
מקומיים), ולעולם לא נשלח לשום מקום — חשוב במיוחד כשמדובר בחומר מוגן
בזכויות יוצרים כמו מבחן אישי.

חי בנתיב `/math-prep/` באתר, בנפרד מהאפליקציות האחרות שבשורש הריפו.

## איך זה עובד

1. **מסמכים** – מעלים קובץ PDF. הוא נשמר ב-IndexedDB של הדפדפן (לא
   מועלה לאף שרת), כך שאפשר לחזור אליו גם בפעם הבאה בלי להעלות שוב.
   בהעלאה, האפליקציה **מזהה אוטומטית** כותרות "Problem N."/"Solution N."
   (או "שאלה"/"פתרון") בטקסט ה-PDF ומפרקת את המסמך לשאלות נפרדות — כל
   אחת עם אזור-שאלה ואזור-פתרון נפרדים, גם כשהם חוצים עמוד. אם לא זוהו
   כותרות (למשל PDF סרוק כתמונה, ללא שכבת טקסט), חוזרים לתצוגה עמוד-עמוד
   פשוטה.
2. **כרטיסיות** – **התצוגה מציגה קודם כל את השאלה בלבד**, גדולה ונוחה
   לקריאה, עם ניווט קודם/הבא, זום, וסימון "יודע" / "חלקית" / "לא יודע".
   הפתרון (התמונה המלאה מה-PDF, פלוס צ'קליסט "שלבי פתרון" ניתן לעריכה)
   מוסתר כברירת מחדל — כפתור אחד "📖 הצג פתרון" פותח אותו, וכשעוברים
   לשאלה הבאה הוא נסגר שוב אוטומטית, כך שכל שאלה מתחילה "נקייה".
3. **נושאים** – שורת תגיות קומפקטית מתחת לשאלה מאפשרת לתייג כל כרטיסייה
   בנושא אחד או יותר (קמירות, תכנון לינארי וכו'), ולהסיר/להוסיף בכל רגע.
   טאב "נושאים" מציג לכל נושא כמה שאלות מתויגות וכמה אחוז מהן "ידועות"
   — כדי לעקוב אחרי התקדמות **לפי נושא**, לא רק לפי שאלה בודדת, ולאורך
   כמה מבחנים/PDF-ים לאורך זמן (הנושאים משותפים לכל המסמכים).

## פירוקים מוכנים מראש

עבור קורס "Mathematical Tools in CS" הספציפי (`EX1_sol.pdf` עד
`EX11_sol.pdf`), האפליקציה **כבר מכילה** פירוק מלא: 44 שאלות מכל 11
התרגילים, כל אחת עם נושא (או כמה נושאים) וצ'קליסט שלבי-פתרון שמדגיש את
הטריק המרכזי בכל שלב — לא רק את הפתרון המלא. פשוט מעלים את ה-PDF, והכל
מופיע אוטומטית: אין צורך ב"פרק אוטומטית" או "ייבוא JSON" ידניים. פרטים
טכניים ב-`manifests/README.md`. כמובן שהתיוג לנושאים ניתן לעריכה מלאה —
אפשר להסיר נושא לא מתאים או להוסיף נושא נוסף לכל שאלה, בדיוק כמו בכל
כרטיסייה אחרת.

עשרת הנושאים המוגדרים כברירת מחדל תואמים את הקורס עצמו: גבולות ורציפות,
נגזרות, קמירות, אופטימיזציה קמורה וגרדיאנט, KKT ולגראנז', תכנון לינארי
ודואליות, אלגברה לינארית ומטריצות, תורת גרפים ספקטרלית, הסתברות ותוחלת,
ושיטות הסתברותיות וריכוז — אבל גם אלה ניתנים לעריכה/הוספה חופשית.

## ייבוא ידני (JSON) — למסמכים שהפירוק האוטומטי לא מזהה

הפירוק לשאלה+פתרון קורה **אוטומטית בכל העלאה** (ראו למעלה) — אין כפתור
ידני להפעיל אותו. אבל אם המסמך לא בפורמט "Problem N."/"Solution N."
(למשל PDF סרוק כתמונה, ללא שכבת טקסט לניתוח), או שרוצים לשלוט בחיתוך
במדויק, אפשר לשתף את ה-PDF עם Claude ולבקש קובץ `questions.json` לפי
הסכימה הבאה, ואז לייבא אותו מטאב **"מסמכים"** — לכל שורת-מסמך יש כפתור
"ייבוא JSON" משלה:

```json
{
  "version": 3,
  "questions": [
    {
      "id": "q1",
      "label": "שאלה 1",
      "questionRegions": [
        { "page": 1, "crop": { "x": 0, "y": 0.12, "w": 1, "h": 0.25 } }
      ],
      "solutionRegions": [
        { "page": 1, "crop": { "x": 0, "y": 0.37, "w": 1, "h": 0.2 } },
        { "page": 2, "crop": { "x": 0, "y": 0, "w": 1, "h": 0.15 } }
      ],
      "topics": ["קמירות", "תכנון לינארי"],
      "steps": ["הצבה בנוסחה", "בדיקת תנאי קמירות", "מסקנה"]
    }
  ]
}
```

- `questionRegions` — רשימת קטעי עמוד שמרכיבים את **גוף השאלה בלבד**
  (מה שמוצג גדול, כברירת מחדל). `solutionRegions` — אותו דבר עבור
  **הפתרון** (מוצג רק אחרי לחיצה על "הצג פתרון"); אפשר להשמיט אם אין
  פתרון נפרד בקובץ. כל קטע הוא `{ page, crop }` כאשר `page` הוא מספר
  העמוד (1-מבוסס) ו-`crop` אופציונלי — מלבן יחסי לעמוד (ערכים 0–1,
  `y`=0 זה **ראש** העמוד). בלי `crop`, הקטע מציג את העמוד המלא.
  לתאימות לאחור נתמכים גם הפורמטים הישנים: `regions` יחיד (כל התוכן
  כ"שאלה", בלי פתרון נפרד), או `"page"/"crop"` בודדים.
- `topics` — שמות נושאים (נוצרים אוטומטית אם לא קיימים).
- `steps` — רשימת שלבי פתרון מוצעים; מתווספים לרשימה הידנית הקיימת.

הייבוא לא מוחק התקדמות קיימת (סימון ידוע/לא ידוע, הערות, שלבים) — הוא
רק מוסיף/מעדכן נושאים, תוויות ושלבים על אותה כרטיסייה (`id`).

## טכנית

- `assets/app.js` — כל הלוגיקה (IndexedDB, רינדור PDF, מצב UI), ES module יחיד, ללא תלויות build.
- `assets/vendor/pdfjs/` — [pdf.js](https://mozilla.github.io/pdf.js/) (MIT), מגובה מקומית מ-npm כדי שהאתר לא יהיה תלוי ב-CDN חיצוני.
- שמירה: IndexedDB (`documents`, `cards`, `topics`) + `localStorage` למסמך האחרון שנפתח. הכל מקומי למכשיר.

לבדיקה מקומית:

```
python3 -m http.server 8000
# פתחו http://localhost:8000/math-prep/
```
