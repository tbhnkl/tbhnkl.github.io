# הכנה למבחן מתמטיקה

אפליקציית ווב אישית, מותאמת למובייל, לתרגול לקראת מבחן מתמטיקה. סטטית
לגמרי, ללא שרת: קובץ ה-PDF נטען ומעובד רק בדפדפן שלך (`File`/IndexedDB
מקומיים), ולעולם לא נשלח לשום מקום — חשוב במיוחד כשמדובר בחומר מוגן
בזכויות יוצרים כמו מבחן אישי.

חי בנתיב `/math-prep/` באתר, בנפרד מהאפליקציות האחרות שבשורש הריפו.

## איך זה עובד

1. **מסמכים** – מעלים קובץ PDF. הוא נשמר ב-IndexedDB של הדפדפן (לא
   מועלה לאף שרת), כך שאפשר לחזור אליו גם בפעם הבאה בלי להעלות שוב.
2. **כרטיסיות** – כל עמוד (או שאלה, ראו "פירוק אוטומטי" למטה) מוצג ככרטיסייה
   נפרדת: ניווט קודם/הבא, זום, וסימון "יודע" / "חלקית" / "לא יודע".
   אפשר גם לפרק כל כרטיסייה ידנית ל"שלבי פתרון" ולסמן מה כבר הבנתם,
   ולהוסיף הערות חופשיות.
3. **נושאים** – מתייגים כל כרטיסייה בנושא אחד או יותר (קמירות, תכנון
   לינארי וכו'). טאב "נושאים" מציג לכל נושא כמה שאלות מתויגות וכמה
   אחוז מהן "ידועות" — כדי לעקוב אחרי התקדמות **לפי נושא**, לא רק לפי
   שאלה בודדת, ולאורך כמה מבחנים/PDF-ים לאורך זמן (הנושאים משותפים לכל
   המסמכים).

## שלב 2: פירוק אוטומטי לשאלות (JSON)

השלב הראשון מציג עמוד-עמוד. כדי לפרק PDF לשאלות נפרדות (כולל חיתוך של
אזור ספציפי בתוך העמוד, נושאים מוצעים, ושלבי פתרון) — שתפו את קובץ ה-PDF
עם Claude ובקשו לייצר קובץ `questions.json` לפי הסכימה הבאה, ואז ייבאו
אותו במסך "כרטיסיות" → "ייבוא פירוק JSON":

```json
{
  "version": 1,
  "questions": [
    {
      "id": "q1",
      "page": 1,
      "label": "שאלה 1",
      "crop": { "x": 0.05, "y": 0.1, "w": 0.9, "h": 0.35 },
      "topics": ["קמירות", "תכנון לינארי"],
      "steps": ["הצבה בנוסחה", "בדיקת תנאי קמירות", "מסקנה"]
    }
  ]
}
```

- `page` — מספר העמוד במקור (1-מבוסס).
- `crop` — אופציונלי; מלבן יחסי לעמוד (ערכים 0–1) לחיתוך רק אזור השאלה
  מתוך העמוד. בלי `crop`, הכרטיסייה מציגה את העמוד המלא.
- `topics` — שמות נושאים (נוצרים אוטומטית אם לא קיימים).
- `steps` — רשימת שלבי פתרון מוצעים; מתווספים לרשימה הידנית הקיימת.

ייבוא לא מוחק התקדמות קיימת (סימון ידוע/לא ידוע, הערות, שלבים) — הוא
רק מוסיף/מעדכן נושאים, תוויות ושלבים.

## טכנית

- `assets/app.js` — כל הלוגיקה (IndexedDB, רינדור PDF, מצב UI), ES module יחיד, ללא תלויות build.
- `assets/vendor/pdfjs/` — [pdf.js](https://mozilla.github.io/pdf.js/) (MIT), מגובה מקומית מ-npm כדי שהאתר לא יהיה תלוי ב-CDN חיצוני.
- שמירה: IndexedDB (`documents`, `cards`, `topics`) + `localStorage` למסמך האחרון שנפתח. הכל מקומי למכשיר.

לבדיקה מקומית:

```
python3 -m http.server 8000
# פתחו http://localhost:8000/math-prep/
```
