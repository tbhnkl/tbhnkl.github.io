# פירוקים מוכנים (bundled enrichment)

הקבצים כאן הם נתונים סטטיים בלבד (JSON) שהאפליקציה טוענת אוטומטית כשמזהה
קובץ PDF מוכר, כדי לחסוך מהמשתמש את הצעד הידני של "ייבוא JSON".

## איך זה עובד

1. כשמעלים PDF, `extractHomeworkNumber()` ב-`assets/app.js` מנסה לחלץ מספר
   תרגיל משם הקובץ (למשל `EX7_sol.pdf` → `7`).
2. אם נמצא מספר, האפליקציה מנסה לטעון `mtcs-hw<N>.json` מהתיקייה הזו.
3. אם הקובץ קיים: מריצים את הפירוק האוטומטי הרגיל (זיהוי כותרות "Problem N."
   בטקסט ה-PDF, כולל שאלות שחוצות עמוד), ואז **דורסים** את הנושאים
   והשלבים של כל שאלה עם הערכים שכתובים כאן (הסימון ידוע/לא-ידוע, הערות,
   ופירוק ידני קיים תמיד נשארים — הדריסה היא רק על נושאים/שלבים).
4. אם לא נמצא קובץ מתאים — האפליקציה פשוט ממשיכה כרגיל (עמוד-עמוד, או
   "פרק אוטומטית"/"ייבוא JSON" ידניים).

## מבנה קובץ

```json
{
  "title": "שם קריא (לתיעוד בלבד, לא מוצג באפליקציה)",
  "questions": {
    "1": {
      "topics": ["קמירות", "נגזרות"],
      "steps": ["שלב ראשון...", "שלב שני עם הטריק המרכזי...", "..."]
    },
    "2": { "topics": [...], "steps": [...] }
  }
}
```

המפתח ("1", "2", ...) הוא מספר השאלה כפי שזוהה מהכותרת "Problem N." בקובץ
המקורי — **לא** מספר סידורי של קובץ ה-JSON.

## הוספת תרגיל חדש

כדי שהעלאת `EX12_sol.pdf` (למשל) תיהנה מפירוק מוכן, הוסיפו כאן
`mtcs-hw12.json` באותו מבנה. אין צורך לשנות קוד — ההתאמה היא לפי שם קובץ.
